Information Collection and Use

The website/app does not require users to create an account.

The website/app uses Google Analytics to collect anonymous usage statistics, such as:

  • App interactions and screen views
  • Device and operating system information
  • Approximate location (country-level only)

This data helps improve website/app performance and user experience.

جمع المعلومات واستخدامها

لا يتطلب الموقع/التطبيق إنشاء حساب.

يستخدم الموقع/التطبيق Google Analytics لجمع إحصاءات استخدام مجهولة الهوية، مثل:

  • تفاعلات التطبيق وعرض الشاشات
  • معلومات الجهاز ونظام التشغيل
  • الموقع التقريبي (على مستوى الدولة فقط)

تساعد هذه البيانات على تحسين أداء الموقع/التطبيق وتجربة الاستخدام.

Online Features

When using optional online features (such as AI-based tafsir comparison), the website/app may send only the user’s query text to external services to generate a response.

No personally identifiable information is included in these requests.

الميزات عبر الإنترنت

عند استخدام الميزات الاختيارية عبر الإنترنت (مثل مقارنة التفسير بالذكاء الاصطناعي)، قد يرسل الموقع/التطبيق نص الاستعلام فقط إلى خدمات خارجية لتوليد الرد.

لا تتضمن هذه الطلبات أي معلومات تعريفية شخصية.

Data Storage

The website/app does not store personal user data on its own servers.

Analytics data is processed by Google Analytics according to Google’s privacy policies.

تخزين البيانات

لا يخزن الموقع/التطبيق بيانات شخصية للمستخدمين على خوادمه.

تُعالَج بيانات التحليلات بواسطة Google Analytics وفقًا لسياسات الخصوصية لدى Google.

Data Sharing

Analytics data is shared only with Google Analytics and is used solely for website/app performance and improvement purposes.

The website/app does not sell or share user data with other third parties.

مشاركة البيانات

تُشارك بيانات التحليلات فقط مع Google Analytics وتُستخدم حصريًا لتحسين أداء الموقع/التطبيق وتجربته.

لا يبيع الموقع/التطبيق بيانات المستخدمين ولا يشاركها مع أي أطراف ثالثة أخرى.

Children’s Privacy

The website/app does not knowingly collect personal information from children.

خصوصية الأطفال
